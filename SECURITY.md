# Security

## Reporting a vulnerability

Do not report vulnerabilities, exploits, leaked keys or passwords in public
issues or pull requests. Email **takwerx@gmail.com** instead. Say what is
affected, the version, and how to reproduce it. If you have a fix, attach or
describe it.

## Supported versions

Only the latest release of Traffic gets fixes.

## What to expect

We reply within 3 working days, work with you privately until a fix ships, and
credit you if you want. Please do not disclose it publicly until a fix is
released.

## Scope

The Traffic plugin code in this repository and the release builds published
here (https://github.com/takwerx/traffic). Bugs in ATAK itself, TAK Server or
other upstream projects belong with those projects. If you are not sure, email
us and we will point you to the right place.
